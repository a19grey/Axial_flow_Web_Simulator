Axial-flux solver, headless

No interface. This page exists so a script can drive the solver without the 3D view or the controls. The API is on window.AFS and is the same module the full page uses.

From a driver: await window.AFS.solve(spec), .score(spec), .sweep(spec, sweepSpec), .validate("all"). Each of these costs GPU time and returns {ok, value} or {ok:false, error} rather than rejecting, because a rejected promise does not survive the automation boundary.

.plan(spec), .capabilities(), .cases() and .defaultSpec() are cheap inspection calls and are the exception: they return their value directly and throw on an invalid design, so catch them yourself.

The command-line driver is node cli/run.js in this repository.

Full description of the API, the spec and what to distrust: llms.txt. The same window.AFS is also defined on the full page, so a driver can watch itself work.
